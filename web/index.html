Sobre este projeto de estágio ＋

O Ritmo usa um classificador Naive Bayes treinado com exemplos para reconhecer o tipo de pergunta. Python e SQL fazem os cálculos; as respostas usam textos definidos no programa. A base inicial é fictícia. O modelo tem alcance limitado e pode pedir que você reformule. O repositório mostra o treino, os erros medidos e as limitações.

A versão local não exige API de IA nem envia a planilha para um provedor de modelo. A conexão PostgreSQL consulta a base que você configurar. O servidor é destinado ao uso local, sem login ou hospedagem pública.
